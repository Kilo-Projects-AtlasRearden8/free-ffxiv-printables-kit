# FFXIV Freebies Kit

Fillable, printable FFXIV printables — no account needed, no game assets, completely free.

A friendly fan project from **Asdale Dynamics, LLC**.

## What's inside

| Printable | What it does |
|---|---|
| [Duty Rotator](duty-rotator.html) | Plan your skill rotation for any duty — opener, burst windows, cooldowns, and notes. |
| [Gil Tracker](gil-tracker.html) | Track gil earned and spent, with totals and a running balance that figure themselves out. |
| [Leve Planner](leve-planner.html) | Plan levequest turn-ins, track allowances used, and mark completion dates. |
| [Mount Checklist](mount-checklist.html) | Track your mount collection, where each one came from, and which ones you still need. |

## How to use

1. **Open any page** in your web browser. No account, no sign-in, and no internet needed once you have the files.
2. **Fill it in** — type directly into the fields on screen, or print the page blank and write by hand.
3. **Print it** — choose File &gt; Print (Ctrl+P on Windows/Linux, Cmd+P on Mac). The on-screen Print button disappears automatically, and the page prints cleanly at 100% scale on US Letter or A4 paper.

## About

This is a fan project made for the FFXIV community. It contains no game assets, no art from Square Enix, and no official game content. It is not affiliated with or endorsed by Square Enix. Final Fantasy XIV is a trademark of Square Enix Holdings Co., Ltd.
