# FFXIV Freebies Kit

Fillable, printable FFXIV printables — no account needed, no game assets, completely free.

A fan project by **Asdale Dynamics, LLC**.

## What's inside

| Printable | What it does |
|---|---|
| [Duty Rotator](duty-rotator.html) | Plan skill rotations (opener, burst windows, cooldowns) per duty. |
| [Gil Tracker](gil-tracker.html) | Track gil earned, spent, and your running balance. |
| [Leve Planner](leve-planner.html) | Plan levequest turn-ins, allowances used, and completion dates. |
| [Mount Checklist](mount-checklist.html) | Track your mount collection, acquisition sources, and what you still need. |

## How to use

1. Open any page in your browser (no account, no sign-in, no network required after download).
2. Fill in the fields on screen, or print blank and write by hand.
3. Choose **File &gt; Print** (Ctrl+P / Cmd+P). Screen controls are hidden automatically and the page prints cleanly at 100% scale on Letter or A4 paper.

## About

This is a fan project made for the FFXIV community. It contains no game assets, assets from Square Enix, or official game content, and it is not affiliated with or endorsed by Square Enix. Final Fantasy XIV is a trademark of Square Enix Holdings Co., Ltd.
