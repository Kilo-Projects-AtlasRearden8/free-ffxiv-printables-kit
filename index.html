How to use

  1. Open any printable page in your browser.
  2. Fill in the fields on screen, or print blank and write by hand.
  3. Choose File > Print (or press Ctrl+P / Cmd+P). Background graphics and screen controls are hidden automatically.
  4. Print at 100% scale on Letter or A4 paper.
